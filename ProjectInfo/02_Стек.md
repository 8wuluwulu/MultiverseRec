
## Основные технологии
| Компонент              | Технология              |
| ---------------------- | ----------------------- |
| Язык                   | Python                  |
| База данных            | PostgreSQL              |
| Векторное расширение   | pgvector                |
| Нейросеть              | -                       |
| Библиотека эмбеддингов | -                       |
| Работа с БД            | psycopg                 |
| ORM                    | SQLAlchemy              |
| Контейнеризация        | Docker + Docker Compose |

## Дополнительные библиотеки
- pandas - для работы с CSV/JSON
- numpy - для работы с векторами
- pytest - для тестирования
- black - для форматирования кода

## Расширения для проекта
- FastAPI - если делать веб-интерфейс
- streamlit - если делать быстрый UI
- redis - для кэширования (опционально)
